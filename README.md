# suhas107.github.io

Personal site of **Suhas Nethi**: dancer, campus leader and full-stack developer at Amrita Vishwa Vidyapeetham, Coimbatore.

Live at **https://suhas107.github.io**

Plain HTML, CSS and JavaScript with GSAP + ScrollTrigger and Lenis for the animations. No build step; hosted free on GitHub Pages.

```
index.html            the page
assets/css/style.css  styles
assets/js/main.js     curtain intro, smooth scroll, reveals, pinned gallery, reels
assets/img/           photos (WebP) and project screenshots
```

To preview locally, run `python -m http.server` in this folder and open http://localhost:8000.
